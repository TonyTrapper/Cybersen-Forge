CYBERSEN FORGE es un framework C2 con interfaz gráfica inspirado en Mythic y Metasploit. Permite gestionar agentes, generar payloads personalizados, administrar sesiones, automatizar tareas y simular operaciones de seguridad ofensiva en entornos de laboratorio e investigación.
